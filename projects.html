Amazon E-Commerce SQL & Power BI Analysis

Problem

Leadership had no unified view of revenue, product profitability, or regional performance — no way to see which products were high-margin vs. high-volume.

Approach

Designed a full e-commerce database schema in SQL Server (ER diagram, joins, window functions, CTEs) and layered a star-schema Power BI dashboard with DAX KPIs on top.

SQL Server Power BI DAX
Key Insight

Analyzed $1.2M revenue, $250K profit (20.8% margin). Electronics was most profitable and North America drove 60%+ of sales — but margin dropped 2.8% month-over-month, flagging a cost/discount issue.
